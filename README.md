# Limpieza & Jardinería de Rosas

Landing page del negocio **Limpieza & Jardinería de Rosas** — servicios de limpieza y jardinería en Madrid y alrededores.

## Estructura

```
.
├── index.html         # Página principal
├── limpieza.html      # Servicio de limpieza (detalle)
├── jardineria.html    # Servicio de jardinería (detalle)
├── img/               # Logo y galería
│   ├── logo.jpg
│   ├── gallery-1.jpg
│   ├── gallery-2.jpg
│   ├── gallery-3.jpg
│   ├── gallery-4.jpg
│   └── gallery-5.jpg
└── README.md
```

## Tecnología

HTML + CSS + JavaScript vanilla. Sin frameworks ni dependencias — solo Google Fonts.

## Cómo publicar en GitHub Pages

1. Sube los archivos a un repositorio.
2. En el repo, ve a **Settings → Pages**.
3. En *Source* selecciona la rama `main` y carpeta `/ (root)`.
4. Guarda. En unos segundos la web estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
